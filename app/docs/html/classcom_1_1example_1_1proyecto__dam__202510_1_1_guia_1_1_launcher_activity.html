Detailed Description

Actividad que gestiona el primer uso de la app para lanzar o no la guia de usuario.

Dispone solo del metodo onCreate que comprueba si es la primera vez que se ejecuta la app. si es así, lanza la actividad GuiaActivity, si no, lanza la actividad MainActivity.
