Detailed Description

Clase que sirve para obtener de la base de datos los datos globales de la applicación para la pantalla de estadistica Esta clase cuando contacta con la base de datos lo hace por la clase especial de Firebase AggregateQuery.

El motivo es eficiencia y el coste de procesamiento es menor que si se hace por get().
